Put your own couple art in this folder (local mode, without Supabase).

1. In the admin panel choose "My own couple art" and press Upload.
2. The file is saved to your Downloads with a new name, for example  m4x2k-dulara.png
3. Copy that file into THIS folder (custom), then upload the whole site to Netlify again.

Tips: transparent PNG, standing full body, about 1000 px tall, under 3 MB.
You can also type a link directly, e.g.  custom/example-groom.png  and  custom/example-bride.png
(those two examples are included so you can test right away).

With Supabase turned on, uploads go to your database automatically: no folder needed.
